DOM Events

Four events, four cards, one script each. No library beyond the stylesheet.

Uppercase as you type

On every input event, the text is copied below in capitals, letter by letter.

Two decimal places

On change, the chosen number is shown with two decimals, toFixed(2): 5.1167 becomes 5.12 and 6 becomes 6.00.

Which key was pressed

On keydown, the event.key property names the key, special ones included: ArrowLeft, Enter, Escape.

 

Colour by window width

On resize, window.innerWidth picks the colour: red under 600 px, green under 900, blue under 1200, none above.
